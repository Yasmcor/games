# 🧱 Jogo Quebra-Blocos

Jogo clássico estilo Breakout/Break-Blocks feito com **HTML5 Canvas** e **JavaScript** puro!

[![Jogar Agora](https://img.shields.io/badge/🎮_JOGAR_AGORA-Quebra--Blocos-00c853?style=for-the-badge&logo=github)](https://yasmcor.github.io/games/)

---

### 🕹️ Como Jogar
- **Controles:** Use as setas **Esquerda (←)** e **Direita (→)** do teclado para mover a plataforma.
- **Objetivo:** Destrua todos os blocos coloridos sem deixar a bola cair no fundo da tela.
